## 发布与权限

保存模型和共享设置只改变草稿。发布校验稳定编号、配件用途、默认组合、引用关系、资源存在及实际哈希，并保存不可变目录快照。界面提交草稿版本指纹，防止另一窗口更新后误发旧数据。替换 GLB 保留历史版本引用的旧文件。回退切换发布快照，不覆盖当前草稿。

`/api/catalog?shop=<shop>` 始终只返回公开零售目录，客户端 audience/scope 参数不能扩大权限。Shopify `/apps/umx-configurator/catalog` 使用官方 App Proxy 签名校验，并根据 Shopify 签名的客户编号读取真实标签。`nb` 优先于 `tob`，完整小写匹配。

- `base`：仅公共模型，价格取服务端核验后的当前渠道；返回中没有全渠道价格表、内部模型或 BOM。
- `library`：登录客户打开模型库后读取其完整可见目录。
- `inventory`：仅内部客户可读取，打开内部工具时才请求。
- 资源链接绑定店铺、发布版本、模型／资源和有效期，带 HMAC，最长六小时；链接过期或版本变化时需刷新。资源响应禁止共享缓存。已授权用户仍能保存其有权查看的文件。
- 所有管理写接口通过 Shopify 员工会话验证。发布使用独立资源接口，避免隧道场景下将 JSON 写操作误当作页面表单。

App 的渠道价用于配置器预估；结账由 Shopify 商品、组合和可信交易规则决定。此次未改商品价格、上架状态、库存或订单。旧商品同步脚本中的重量／SEO／上架资料属于 Shopify 商品运维输入，不作为配置器目录运行时数据。

## 迁移命令

使用私有 JSON 清单，结构包含 models（file、thumbnail、thumbnailLight、metadata、config）、settings 和 environment。文件路径必须位于指定资源目录；缩略图与环境资源在导入时转为 App 资源编号。实际清单不可提交公开仓库。

```sh
node --env-file=.env --import tsx scripts/import-catalog.ts /private/catalog-import.json /private/assets example.myshopify.com
```

首次导入前备份数据库与资源目录。导入已有但不一致的记录会中止；浮点持久化的机器精度差异不视为业务修改。仅导入草稿，随后在 App 中检查并发布。
